System Overview

The Point of Sale (POS) system is designed as an offline-first distributed application. The central source of truth operates under an Eventual Consistency model, where local transactions act as the immediate source of truth while the device is offline, and background queueing synchronizes state via Firebase Firestore when an internet connection is available.

Quick Summary

Component Implementation Details

Online-Only Features Authentication (SignIn/SignUp), Initial Full Pull
Sync Engine Push: Queue-driven exponential backoff. Pull: Incremental pagination via updatedAt
Conflict Resolution Server-side: Last-Write-Wins (LWW). Client-side: Unsent local changes win over remote pulls.
Idempotency Firestore SetOptions(merge: true) with UUIDs.
