Sync Engine Deep Dive

The synchronization engine (SyncService) runs purely as a background worker, triggered by connection state changes, timer fallbacks, and auth state changes.

Push Synchronization

The push sync relies on an Outbox Pattern using Hive CE (SyncQueueBox).

  1. Every local mutation (create/update/delete) creates or updates a SyncQueueItem.
  2. Pending items for the same entity are collapsed—if a user updates a Product 5 times while offline, the queue keeps only 1 entry with the final state.
  3. Upon sync trigger, a batch of 20 items is processed.
  4. The JSON payload is dynamically constructed at upload time (not at queue time). If an item was deleted locally before upload, the sync item is quietly removed without uploading.
  5. The engine uses Firestore commitBatch for atomicity.

Pull Synchronization

Pull synchronization is heavily optimized to be incremental.

Incremental Pagination

The pull sync uses updatedAt cursors to fetch only records changed since the last fully successful pull. The request is paginated using limit(300) and processed sequentially to maintain a low memory footprint.

State Machine & Retries

stateDiagram-v2 [*] --> PENDING PENDING --> SYNCING : Process Queue Batch SYNCING --> COMPLETED : Success (Deleted from Queue) SYNCING --> FAILED : Error FAILED --> PENDING : Exponential Backoff Timer FAILED --> DEAD : Max Retries Exhausted (5)

Exponential Backoff: The retry delay is calculated as 2^retryCount * 30 seconds.

Delete Synchronization

Deletions are handled using soft-deletes (tombstones) on some entities via isDeleted flags. However, the sync queue explicitely supports hard deletes (action: 'DELETE'). When an action is 'DELETE', the SyncService adds a SyncWrite.delete() command to the Firestore batch.

Timestamps & Clocks

Locally, devices rely on their own clocks for updatedAt. However, when pushed, the server enforces syncedAt: FieldValue.serverTimestamp(). Pull sync filtering relies on the entity's updatedAt, which is vulnerable to client device clock drift if two devices have significantly divergent times.
